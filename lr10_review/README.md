показані стеля годин, планова трудомісткість і формула стелі. У своєму
[WBS ЛР7](../lr07_wbs/README.md) застосував такий самий підхід: 836 год
плану проти 900 год стелі, плюс окрема перевірка завантаження Dev і QA.
